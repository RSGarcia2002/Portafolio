# Portafolio de Randall Garcia

Sitio web estatico para presentar proyectos relevantes de GitHub durante busqueda laboral.

## Archivos

- `index.html`: estructura principal del sitio.
- `styles.css`: estilos responsive.
- `script.js`: datos de proyectos y renderizado de tarjetas.

## Uso local

Abre `index.html` directamente en el navegador o usa un servidor local:

```bash
python3 -m http.server 5173
```

Luego visita `http://localhost:5173`.

## Publicacion sugerida

Este proyecto se puede publicar con GitHub Pages desde la rama principal.
